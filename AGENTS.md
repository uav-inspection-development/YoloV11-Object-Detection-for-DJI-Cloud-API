# Project Agents.md Guide for OpenAI Codex

This `Agents.md` file provides comprehensive guidance for OpenAI Codex and other AI agents working with this codebase.

---

## Project Overview

This project focuses on detecting solar panel anomalies in photovoltaic farms using **Visible**, **EL (Electroluminescence)**, and **Thermo (Infrared)** images. It includes training models, deploying them, and performing detection on images, videos, and real-time camera feeds.

---

## Project Structure for OpenAI Codex Navigation

- `/src`: Source code that OpenAI Codex should analyze
  - `/components`: React components for UI (if applicable)
  - `/pages`: Next.js pages for route handling
  - `/utils`: Utility functions for preprocessing and postprocessing
  - `/models`: Model definitions and YOLOv8 integration
  - `/web.py`: Web interface for detection
  - `/ui.py`: Main interface for detection
- `/public`: Static assets (OpenAI Codex should not modify these directly)
- `/tests`: Test files that OpenAI Codex should maintain and extend
- `/output`: Logs and detection results
- `/weights`: Pre-trained YOLO weights
- `/runs`: Stores training results and weights
- `/util_data`: Dataset processing tools

## Programmatic Checks for OpenAI Codex

Before submitting changes, install development dependencies and run the following checks:

### Installation

```bash
# Install development dependencies
pip install -r requirements-dev.txt

# Or use the helper scripts
# On Linux/Mac:
make install-dev

# On Windows:
.\dev.ps1 install-dev
```

### Code Quality Checks

```bash
# Lint check with flake8
flake8 src

# Type check with mypy
mypy src

# Run tests with coverage
pytest tests/ --cov=src --cov-report=term-missing

# Format code (optional but recommended)
black src tests
isort src tests
```

### Using Helper Scripts

```bash
# On Linux/Mac (using Makefile):
make lint        # Run flake8
make type-check  # Run mypy
make test        # Run pytest with coverage
make format      # Format code with black and isort
make check       # Run all checks (lint + type-check + test)
make clean       # Clean cache files

# On Windows (using PowerShell):
.\dev.ps1 lint        # Run flake8
.\dev.ps1 type-check  # Run mypy
.\dev.ps1 test        # Run pytest with coverage
.\dev.ps1 format      # Format code with black and isort
.\dev.ps1 check       # Run all checks (lint + type-check + test)
.\dev.ps1 clean       # Clean cache files
```

All checks must pass before merging.

## Example Commands for OpenAI Codex

### Training the Model

```bash
python src/train_interface.py --task Detection --workers 4 --batch 8 --device 0 --data_name my_dataset --epochs 100 --img_size 640
```

### Running the Detection Interface

```bash
python main.py --run-mode=streamlit --secret-key=YOUR_SECRET_KEY --license-file=license.dat --bind-info-file=bind_info.json
```

### Running the Detection API

```bash
python main.py --run-mode=api --oauth2-introspect-url=$OAUTH2_INTROSPECT_URL --client-id=$CLIENT_ID --client-secret=$CLIENT_SECRET --secret-key=$YOUR_SECRET_KEY --license-file=license.dat --bind-info-file=bind_info.json
```
